HOW TO USE
- Start a fresh SIMBA chat for each independent question.
- For category 16, send the Turn 1 / Turn 2 / Turn 3 parts sequentially in ONE chat, not as a single message.
- Copy the exact SIMBA reply, not your own summary.
- Record whether it answered accurately, remembered facts, avoided irrelevant cards/links, and offered one relevant next step.
- Do NOT paste all 400 questions into one SIMBA conversation; that would invalidate independence.
- If you have a staging test runner, run these as isolated conversations and export question/answer pairs.
- No tax answer key is supplied here; tax accuracy must be independently checked against current HMRC guidance.
