This is an optional offline planning aid, not a tax return or a filing confirmation.
Keep completed notes securely. Do not add passwords or one-time security codes.

PRACTICAL TASK
Make the platform totals agree before combining them Create one line per app with gross earnings, refunds, fees, other adjustments and net payout. Add the lines only after each reconciles. Keep a separate list for cash tips and direct bookings that never appeared on an app. For example, if an app’s annual summary covers January to December, mark which months belong in each UK tax year. Do not add it to an April-to-April export of the same earnings. The same delivery must appear once, even where several reports describe it.
